# Pro Editor 완성 계획 (전수) — 2026-07-22

지수2 작성. 기준: TK님 원칙 "CapCut/DaVinci/Descript보다 낫거나 최소 안 밀린다. 밀리면
사용자 불평." 전제: 참가자는 외부 도구·외부 업로드 불가 → 우리 도구가 부족하면 그 참가자는
작품을 제대로 못 만들고 끝난다(선택지 없음 = 우리 책임 가중). 상금 최대 $250k 리그.

핵심 판정 기준(★): **"이게 없으면 참가자가 좋은 작품을 못 만드는가?"** — 있으면 좋은 것과
없으면 품질이 떨어지는 것을 가른다.

## 1. 우리가 지금 가진 것 (코드 실측)

- **타임라인**: 단일 비디오 트랙 — 순서(드래그)·트림(양끝)·하드컷. 줌. 클립수/길이 캡.
- **프리뷰**: WYSIWYG GL 엔진(색보정/LUT/glow/grain) + raw 폴백, **스크럽/시크·재생/정지
  (클릭/스페이스)·playhead·시간표시**(오늘 추가), 검정화면 방지 가드.
- **효과(클립별 + 전체 그레이드)**: 노출·대비·채도·색온도·틴트·비네트·glow·grain 슬라이더 +
  **LUT(룩)** + **속도(0.25~4x, 고정값)**. 미노출(구현됨): sharpen·chromatic·lutIntensity·motionBlur.
- **전환**: crossfade + 와이프 4종 노출. (그 외 미노출)
- **Undo/Redo**(효과+구조), 초기화 버튼, 슬라이더 더블클릭 리셋 (오늘 추가).
- **오디오**: 클립 원음 재생 + 전환부 acrossfade만. 음악·볼륨·페이드 **없음**.
- **렌더**: 워커 ffmpeg, WYSIWYG 패리티, CryptoBind 서명.
- **우리만 있는 것**: ①AI 생성과 묶인 **출처증명(CryptoBind) + WYSIWYG 색보정** ②Genesis Rule

## 3. 결손 항목별 판정 (공수 / 리스크 / ★없으면 좋은 작품 불가?)

> "좋은 작품 불가?" = **YES**면 발사 블로커급, **NO**면 있으면 좋은 것.

### A. ★자막/텍스트/타이틀 — **없으면 좋은 작품 불가: YES (최우선)**
광고에 **제품명·카피·CTA·자막**을 못 넣는다. CF에서 치명적 — 텍스트 없는 광고는 아마추어로
보이고 "도구가 못 따라줘서"의 대표 사례가 된다. 경쟁 4종 전부 보유.
- 필요: EDL 텍스트 오버레이 데이터모델(양 레포 + CryptoBind canonical 확장) · 워커 ffmpeg
  `drawtext`(폰트 KO/EN·위치·타이밍·페이드·외곽선) · **프리뷰 WYSIWYG**(DOM 오버레이를
  drawtext와 정합 — GL 효과처럼 패리티가 관건) · UI(문구·폰트·크기·색·위치 9그리드+드래그·
  구간) · **참가자 입력 텍스트 모더레이션 필수**.
- 공수: **5~6 dev-day**(정적 텍스트 v1). 애니메이션 텍스트까지면 +2~3.
- 리스크: **높음** — 프리뷰↔렌더 패리티, 한글 폰트, 모더레이션.

### B. ★음악/오디오 — **없으면 좋은 작품 불가: YES (HIGH)**
광고는 사실상 절반이 소리다. 음악 없으면 30~40초가 죽는다. (별도 공수보고 기제출: 라이브러리
+ AI생성 + WYSIWYG.)
- 공수: 라이브러리+믹싱+WYSIWYG(**Stage 1) ~5~6 dev-day**, AI생성(Stage 2) +1.5~2.
- 리스크: 중~높음(워커 양경로 믹싱, 오디오 WYSIWYG 마스터클록). 상세=별도 음악 공수보고.

### C. 종횡비/리프레임 — **판정: 시즌 포맷 결정에 달림 (TK 결정 필요)**
시즌이 **단일 종횡비 고정**(예: 16:9)이면 참가자가 그 비율로 생성 → 리프레임 불필요(NO).
혼합 허용이면 크롭/패드 UI+렌더 필요(YES). 지금 렌더는 최소 해상도 캔버스 다운스케일만.
- 공수: 고정이면 0 / 혼합 지원이면 2~4 dev-day.

### D. 키프레임 애니메이션 — **없으면 좋은 작품 불가: NO (있으면 크게 향상)**
효과값이 전 구간 고정. 켄번즈(팬/줌)·펀치인·텍스트 이동 불가. 30~40초 멀티컷 광고는
고정값으로도 성립하나, 생동감 천장이 낮다. CapCut/Runway 보유.
- 공수: **5~8 dev-day**(EDL 시변 모델·워커/프리뷰 보간·타임라인 키프레임 UI). 리스크 높음.
- 저비용 대안: **켄번즈/팬줌 프리셋**(풀 키프레임 없이 시작·끝 값만) 2~3 dev-day → 생동감의
  80%를 싸게 확보. 판정 NO지만 가성비 높음.

### E. 클립 분할(split) — **없으면 좋은 작품 불가: 경계 (NO, 우회 존재)**
가운데에서 자르기 없음(트림은 양끝만). 우회: 같은 클립을 두 번 추가해 각각 트림 → 반쪽 확보
가능(EDL이 동일 클립 다구간 지원). 정식 split은 편의.
- 공수: **1~2 dev-day**(playhead에서 분할 → 두 세그먼트). 리스크 낮음.

### F. 보이스오버/TTS — **없으면 좋은 작품 불가: NO**
클립에 이미 원음/대사 존재 + 텍스트로 메시지 전달 가능. 나레이션 광고엔 좋지만 필수는 아님.
- 공수: 오디오 인프라(B) 위에 +2~3 dev-day.

### G. 전환 다양성/모션블러/sharpen/chromatic — **없으면 좋은 작품 불가: NO (폴리시)**
대부분 이미 구현·미노출. 패리티 검증 후 노출만.
- 공수: 항목당 **0.5~1 dev-day**.

### H. 속도 램프 — **NO** (키프레임 하위집합). 공수 키프레임에 흡수.

### 우리가 안 넣는 것 (Genesis Rule): PiP/오버레이/스티커/외부 로고/크로마키/외부배경 합성.
→ 규칙상 금지가 맞다. 단, **"제품명/카피 텍스트"는 외부 소재가 아니라 창작자 카피**이므로
Genesis에 위배 아님 — 텍스트는 반드시 넣어야 한다(A 참조).

## 4. 단계 구분안

### Phase A — 발사 필수 (참가자가 compose로 최종본 만들기 전까지 반드시)
1. **텍스트/자막 v1** (A) — 공수 5~6 d, 리스크 높음
2. **음악 Stage 1(라이브러리+WYSIWYG)** (B) — 공수 5~6 d, 리스크 중~높음
3. (여유 시) 전환/sharpen 패리티 후 노출 (G) — ~1 d
→ **합계 ~11~13 dev-day.** 이게 정직한 블로커 셋이다.

### Phase B — 시즌 중 추가 가능 (초반에)
- 음악 Stage 2(AI 생성) ~2 d · 클립 split ~1~2 d · 켄번즈/팬줌 프리셋 ~2~3 d ·
  보이스오버 ~2~3 d · 전환/모션블러 추가 노출 ~1 d

### Phase C — 시즌 1 이후
- 풀 키프레임 애니메이션 ~5~8 d · 고급 색보정(커브/HSL) · 종횡비 리프레임(시즌 포맷이
  요구하면 앞당김) · 속도 램프

## 5. ★TK님 결정 필요 사항
1. **시즌 출력 종횡비**: 단일 고정(16:9 등) vs 참가자 선택 — C(리프레임) 필요 여부·시점 결정.
2. **Phase A 일정 현실성**: text+music ~11~13 dev-day는 오늘(D-3, 7/25) 안에 검증완료 **불가**.
   compose/제출 창이 7/25보다 **얼마나 뒤인지**(=대기 중 일정 4건의 "예선 마감일")에 따라:
   - 창이 2~3주 뒤 → Phase A 안전하게 투입 가능.
   - 창이 7/25 근접 → **text·music을 검증완료로 못 맞춤 → 발사 범위 재조정 필요**
     (예: 텍스트만 먼저 / 음악 라이브러리 최소만 / 나머지 시즌 중).
3. **텍스트가 음악보다 우선순위 위인지**: 내 판단 = **텍스트 우선**(광고에서 제품명 부재가
   음악 부재보다 치명적). 두 개 다 필수지만 하나만 먼저면 텍스트.

## 6. 솔직한 총평
- 우리는 **색보정·무결성**에선 경쟁 도구를 앞선다(우리만의 WYSIWYG 그레이드+출처증명).
- 그러나 **광고의 기본기 2종(텍스트·음악)이 통째로 비어 있다.** 이건 "있으면 좋은" 게
  아니라 "없으면 광고를 완성 못 하는" 결손이다. 특히 **텍스트**.
- 나머지(키프레임·split·보이스오버·전환)는 품질을 올리지만 없어도 좋은 작품은 가능 →
  시즌 중/후.
- 즉 **발사 필수 = 텍스트 + 음악.** 이 둘의 일정 확보가 이번 판단의 핵심이다.
