## 3. 구현 설계 (B안, 승인 후 착수)

- **설정 키 2개**(값 = 언어 짝 JSON 배열 `[{"en":"<id>","ko":"<id>"},...]`, 한쪽 없으면 `en`으로 대체, 비어 있으면 아무것도 안 나옴): 이름 초안 `tournament_promo_competition`, `tournament_promo_oxxovo`. (실제 키 이름·`value_type`은 착수 시 확정. 짝 형식 이유는 `reports/promo_allowlist_draft.md` §4.)
- **읽기**: 서버 전용 함수가 키를 읽고 `promo_videos`에서 **명시 칼럼만** 읽는다(`id, video_url, duration_seconds, aspect_ratio, actual_width, actual_height` 정도). `select *` 금지(프롬프트·비용·Postiz id 등이 있는 표).
- **읽는 시점 재확인(fail-closed)**: `deleted_at is null`, `status = 'ready'`, 주소가 https이고 호스트가 `R2_PUBLIC_BASE`와 같음(배너 읽기와 같은 규칙), 목록 최대 개수 상한, id 형식 검증. 하나라도 어긋난 항목은 조용히 제외.
- **참가작과 섞이지 않음**: 이 컴포넌트는 `getWatchVideos`·`genesis_applications`를 import하지 않는다(소스 가드 시험). 카드 라벨은 데이터가 아니라 **코드 상수**(새 badge `promo`, 카탈로그 문구는 제니3).
- **플레이어**: `<video preload="metadata" playsinline controls>`, 자동재생 없음, 세로 카드. 포스터 파일 불필요(첫 프레임).
- **페이지**: `/competition` 두 그룹 섹션. redirect 처리는 TK님 답 후(제안: redirect 제거 + 대회 공개 시 연결 카드, `/watch` 코드는 건드리지 않음).
- **시험**: 허용 목록 파싱(순수 함수), 삭제·비ready·외부 호스트 제외, 상한, 참가작 호출 없음 소스 가드, 키 비면 빈 틀. 가드는 일부러 망가뜨려 빨개지는 것 확인 + 대조군.
- **켜기·끄기**: 키 값 비우면 즉시 끔(배포 불필요). 값을 넣는 SQL은 한 블록 한 쿼리, Run 뒤 공백 오염 검사(`value ~ '\s'`).
