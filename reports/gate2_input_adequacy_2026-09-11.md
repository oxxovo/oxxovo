# Gate 2 — Input Adequacy 공식 판정 (Step 0, 2026-09-11, 새 API 호출 0건)

방법: 각 클립의 **실제로 모델에 전달된 프레임 세트**(원래 pilot이 쓴
파일 그대로, `oxxovo-scoring/temp/frames_*`)를 직접 열람 + **로컬
ffmpeg로 원본 video.mp4에서 1fps 덴스 재추출**(새 다운로드 없음, 이미
받아둔 파일만 사용)을 "원본 전체 타임라인" 근사치로 대조. ⚠️방법론적
한계: 1fps도 여전히 표본이다(원본 네이티브 프레임레이트 전체는 아님) —
찰나의 1~2프레임짜리 결함은 이 audit도 놓칠 수 있다. 아래 판정은 이
한계 안에서다.

## demo_duel (E, 정체성 드리프트 후보)

- 원래 전달 프레임: 0/2/4/6/8/10/12/14초(8장). 덴스 재추출(1fps, 15장)로
  전체 타임라인 대조 완료.
- 여성 캐릭터(파란 에너지) 머리: 0~9초 구간은 일관되게 짙은 밤색·풍성·
  바람에 날리는 형태(`f_009`=8초 직접 확인). 12~14초 구간은 더 밝고
  뒤로 넘겨진 형태(`f_014`=13초 직접 확인). **차이 자체는 덴스·원본
  전달분 모두에서 동일하게 확인된다 — 전달 프레임 밖 구간에서 사라지는
  정보가 아니다.**
- 그런데 동시에, 이 차이가 "정체성이 바뀐 것"인지 "충돌 직전 자세·풍압으로
  머리가 뒤로 눌리고 조명이 붉은 폭발광으로 바뀌며 생긴 자연스러운 변화"
  인지, **덴스 프레임으로 봐도 기계적으로 확정이 안 된다** — 전환 자체가
  약 2~3초 구간에 걸쳐 일어나고, 물리적으로 불가능한 수준의 급변은
  아니다.
- **판정: PARTIAL.** 존재 자체는 확인됐지만("정보 없음"이 아님), 그
  차이를 identity-continuity 결함으로 확정할 만큼 명확하지 않다 —
  조명·자세·풍압이라는 그럴듯한 대안 설명이 남는다. **이걸 모델 Miss로
  몰면 안 된다** — Claude의 기존 답("identity is preserved, rendering
  register만 변함")은 이 애매함 안에서 **방어 가능한 해석일 수 있다.**
  지난 보고서의 "Misattributed" 단정은 과도했다 — 정정한다.

## demo_anne (C, 모션 결핍) — ★2개로 분리 판정

원래 전달 프레임 8장(0~14초) + 덴스 15장(1fps, 전체 15.07초 커버) 전부
직접 확인. **15장 전부에서 다리·발이 단 한 프레임도 화면에 안
들어온다**(전부 허리~허벅지 선 크롭, 구도가 클립 내내 거의 고정).

- **(a) "모션 결핍을 못 봤다"(누락)**: 판정 = **ADEQUATE.** 다리가
  안 보인다는 사실이 전달된 8장 전부에서, 그리고 덴스 15장 전부에서
  동일하게 확인된다 — 전달 구간 밖에 걸음걸이가 숨어 있을 여지가
  없다(전체 타임라인 자체가 그렇게 찍혔다). "다리 상태를 확인할 수
  없다"고 답하는 데 필요한 증거는 전달분에 이미 충분히 있었다 — 이건
  순수하게 모델/절차 문제다.
- **(b) "안 보이는 동작을 있다고 만들어냈다"(捏造)**: 판정 = **ADEQUATE**
  (같은 근거) — 다만 이건 (a)와 **다른 종류의 실패**다. (a)는 누락
  (있는 걸 못 봄), (b)는 창작(없는 걸 있다고 씀 — 기존 STEP 1
  observation이 "medium-wide, knees/full-body"라고 어떤 프레임에도
  없는 프레이밍까지 적었다). STEP 1 자체가 "Record only what is
  visibly present"를 명시하는데 이걸 정면으로 어겼다 — 단순 누락보다
  심각도가 높다(사실 확인 계층 자체의 신뢰성 문제).

## Z03_studio (TRAP, 인물 교체)

- 원래 전달 프레임 10장(0~18초) + 덴스 19장(1fps) 전부 확인. Subject A
  (동아시아 여성, 생머리, 원숄더 레드 새틴) 구간과 Subject B(흑인 여성,
  중년, 곱슬 단발, 레드 벨벳) 구간이 컷 전후로 **매우 명확하게, 여러
  프레임에 걸쳐** 확인된다 — 인종·나이·헤어스타일·의상 재질 전부 다름,
  모호함의 여지가 없다.
- **판정: ADEQUATE.** 정보는 차고 넘친다. 이 사례의 실패는 100%
  interpretation 단계(관찰된 사실을 위반으로 분류 안 함) 문제이고,
  input adequacy와는 무관함이 이번 audit으로 재확인됐다.
