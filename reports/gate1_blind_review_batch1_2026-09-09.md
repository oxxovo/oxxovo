# Gate 1 Blind Review — Batch 1 (Independent Review, Reviewer 2)

Method: for each pair, pulled duration via `ffprobe`, extracted 9-12 frames spread evenly across the FULL duration of both clips via `ffmpeg` (contact-sheet tiles), and for anything ambiguous or suspicious pulled additional close-spaced high-resolution frames around the specific moment in question. Judged purely on what I saw — no prior scores or other reviewer's notes were consulted.

Note on process integrity: I extracted all frames into my own isolated scratch subdirectory to avoid any cross-contamination with a concurrent process that appeared to be using the shared scratch folder at the same time.
