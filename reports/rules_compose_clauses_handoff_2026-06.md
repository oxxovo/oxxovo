## 현재 /rules에 들어간 짜깁기 조항 (영문, feat/studio-compose)
- **§⑥ 상단 R0 기준선 헤드라인 박스** (커밋 9ae2a6c + KO 병기 fd1b39d):
  - EN: "Baseline: what the AI generated is allowed — what you add in post is not."
  - KO: "기준선: AI가 생성한 것은 허용 — 후편집으로 추가한 것은 금지."
  - 보조 설명문 1단락(영문): within=allowed / afterward=not / 편집기에 add도구 없음.
- **Genesis Rule** 자체는 아직 /rules 본문에 별도 섹션으로 없음 — 편집기 UI(ComposeEditor) + 설계doc §6에만. 지수 통합 시 /rules에 짜깁기 섹션 신설 필요.

## TK 지시 — 리포맷 요건 (지수가 통합할 형태)
1. **번역강한 리포맷**: 긴 문장 ❌ → 짧은 문구 + 숫자 + 아이콘 + **표** 위주. (자동번역 오역 최소화 + 영어 모르는 사람 보호)
2. **KO 추가**: 새로 쓰지 말고 **카피키트 v6 표현 재사용**.
3. **HTML 실제 텍스트** (이미지 ❌ → 브라우저 자동번역 작동).
4. **영어 원문 = 분쟁 기준**: 지수가 페이지 전체에 고지문 넣을 예정 → 짜깁기 조항도 그 틀에 맞게.

## 리포맷 초안 방향 (지수2 제안, 본정리 시 확정)
- "허용 vs 금지" **2열 표**:
  | ✅ 허용 (AI 생성물) | ❌ 금지 (후편집 추가) |
  |---|---|
  | 클립 안의 글자·효과·전환 | 후편집 글자·효과·전환 |
  | 클립 자체 AI 오디오 | 외부 오디오 추가·믹싱 |
  | 순서·트림·컷 | VFX·색보정·모션그래픽·외부에셋·업스케일 |
- 허용 동작 **3개 아이콘 칩**: 순서 / 트림 / 컷
- "30초 / 본인 클립만 / OXXOVO 편집기 내" = 숫자+짧은 라벨
- 카피키트 v6에서 해당 KO 문구 키 매핑(본정리 시 grep).
